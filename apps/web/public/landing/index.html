工作方式How it works

不是文档旁边的聊天框More than a chat box next to your document

大多数 AI 写作工具要你把文字复制进去，再把回答粘贴回来。TeXdraft 里的 Agent 像编程 Agent 一样自己动手，每次运行都走完这一圈。Most AI writing tools make you copy text in and paste answers back. In TeXdraft the agent does the work itself, the way coding agents do, and every run goes through the full loop.

  1. 01

    读Read

    打开相关文件，搜全项目，看大纲和引用关系。Opens the relevant files, searches the project, checks the outline and references.

    read_filegrepget_outline
  2. 02

    改Edit

    以最小改动写进共享文档，不会覆盖合作者正在输入的内容。Writes minimal edits into the shared document without clobbering a co-author's typing.

    str_replaceapply_patch
  3. 03

    编译Compile

    在沙箱里编译，拿到带源码行号和提示的报错。Compiles in a sandbox and gets errors with file, line and hints.

    compileget_compile_diagnostics
  4. 04

    看 PDFCheck the PDF

    查看渲染出来的页面，确认图表位置和排版。Looks at the rendered pages to check layout and where figures land.

    get_pdf_pages
  5. 05

    汇报Report

    告诉你改了什么。运行前已存检查点，一键撤销。Tells you what changed. A checkpoint was saved first, so one click undoes it.

    restore_version

Or use the built-in agent with your own key for Claude, DeepSeek, OpenAI, Gemini, Qwen, Kimi, GLM, OpenRouter or a local Ollama model.

为合作者设计Built for co-authors

多人实时编辑，看得到彼此的光标，分所有者、编辑者、只读三种角色。AI 的修改和人的输入同时发生也不会冲突。Real-time collaboration with live cursors and owner, editor and viewer roles. AI edits and human typing can happen at the same moment without conflict.

每一步都可追溯Every step is traceable

  • 每次 AI 运行前自动存检查点，随时撤销Every AI run is checkpointed and can be undone
  • Agent 只能访问你授权的项目，碰不到你电脑上的文件Agents reach only the projects you grant, never the files on your computer
  • 编辑记录写明谁改了哪几行，是人还是 AgentThe edit log shows who changed which lines, person or agent
  • 编译在沙箱里进行，与服务器隔离Compiles run in a sandbox, isolated from the server

开源，部署在你自己的服务器Open source, on your own server

AGPL-3.0 开源，一条 Docker 命令部署，镜像自带支持中文的 TeX Live。论文留在你的服务器上，也不会被某一家模型厂商绑定。AGPL-3.0, self-hosted with one Docker command, TeX Live with CJK support included. Your papers stay on your server, and you are never locked into one model vendor.

运行一个无依赖的单文件桥接程序，电脑不需要公网 IP。Agent 只能用 TeXdraft 的工具，本机的 shell 和文件都被关掉。Run a single-file bridge with no dependencies; no public IP needed. The agent can only use TeXdraft's tools: shell and local file access are switched off.

# Node.js 22+
curl -fsSL \
  https://texdraft.app/mcp/bridge.mjs \
  -o texdraft-bridge.mjs

私有化部署Self-host

一条命令，部署到你自己的服务器One command on your own server

镜像自带支持中文的 TeX Live。打开 http://127.0.0.1:8787 注册，第一个账号自动成为管理员。在线体验版有用量限制，正式使用建议自己部署。TeX Live with Chinese support is included. Open http://127.0.0.1:8787 and sign up; the first account becomes the administrator. The public demo has usage limits, so self-host it for real work.

在 GitHub 上查看View on GitHub 部署指南Self-hosting guide 
git clone https://github.com/songboyangy/texdraft.git
cd texdraft
cp deploy/.env.example deploy/.env
# POSTGRES_PASSWORD, SESSION_SECRET, PUBLIC_URL, AI key
docker compose -f deploy/docker-compose.yml up -d --build
